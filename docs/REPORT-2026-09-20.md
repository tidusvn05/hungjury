## What shipped

### P0 — eval ergonomics (the footguns hit during the loop)

| Item | Change |
|---|---|
| report overwrite | `--report` optional; defaults to `eval-<label>.json` so runs stop clobbering each other |

## Design notes

- **Throwaway memory db per eval seed** is the load-bearing change: the
  manual loop's "wipe memory.db between seeds" step is now the default,
  and `eval` can never contaminate production rulings.
- `aggregate` only appears when `--seeds > 1`; a single-seed report is
  byte-identical in shape to before (plus `per_key`).
- `lint` is warnings-only (exit 0) — a heuristic can't prove a rubric
  wrong, it can only flag the shapes that measurably cost accuracy.

## Follow-up measurement — 64 cases × 3 seeds, `--audit-train 8`

`eval --seeds 3 --seed 11 --audit-train 8 --label adv64`
(`examples/support-triage/eval-adv64.json`):

| arm | mean | min–max | memory_injected |
|---|---|---|---|
| jury | 95.7% | 93.6–96.8% | 0 |
| jury+memory | **98.6%** | 97.9–100% | ~220 |
| judge cold | 100% | — | 0 |
| judge_informed | 100% | — | 0 |

`go_pass 3/3`, `memory_delta_vs_jury` mean +2.9pts, `gap_closed`
0.67–1.0. The audit path fixed the s8 memory no-op permanently: every
seed had rulings to inject because judge re-judging emits
rulings/precedents at full trust on jury-decided keys — escalation is
no longer the only memory source. Abstention held under memory: all
arms kept `department` hung on the 4 information-free cases.
Residual jury misses are all `frustration` off-by-one — the known
label-boundary noise floor.

Also verified the `expected: "hung"` scoring path end-to-end and fixed
the abstention-case labels (only `department` expects hung; an empty
ticket is defensibly calm/non-urgent).

`promote_rulings` granularity caveat: left as documented limitation —
one confirmation graduates all provisional rulings on that qid scope;
per-decision linkage would need a schema change and `trust` only ranks
injections today.

## Multi-angle review pass (post-measurement)

Found and fixed:

- **`score_judge` hung-expectation asymmetry** — a judge abstaining on
  a `expected:"hung"` key counted `hung` but never `correct`, and its
  `decided` denominator differed from jury arms. Judge arms now score
  abstention identically to jury arms (decided++ + correct iff
  abstained). With adv64 this hid judge's correct abstentions.
- **`--label` filename traversal** — `eval-../x.json` escaped the cwd.
  Labels are now sanitized to `[alnum._-]` for the default report path.
- **`judge_informed.memory_injected` always 0** — the informed judge
  *did* retrieve memory but the metric never counted it; now reports
  `used.rulings+precedents+facts` like the jury-memory arm.
- **`doctor` side effect** — `Store::open` created `memory.db`, schema
  and a machine id on a fresh project just by running diagnostics.
  Doctor now reports "not created yet" without touching the fs.
- **`learn --audit`/`learn --queue` abort on one corrupt decision row**
  — a single malformed stored request/response killed the loop via `?`.
  Both now log-and-skip (`parse_stored`); `feedback` still errors on a
  bad row, which is correct for a single-target command.
- **eval seed-failure atomicity** — one seed error discarded every
  completed seed's report. Failures now record into `seed_errors` and
  the run continues; the command only fails when *all* seeds failed.
- **TS SDK** — nonzero exits other than 0/2 and unparseable stdout now
  raise `HungjuryError` instead of leaking a bare `SyntaxError`.
- **`lint` warns on an empty questions map** (`{}`).
- Defensive: eval mismatch path no longer indexes `resp.answers[key]`
  (a missing key now reports `"got": "missing"`).

Checked and confirmed clean: cache isolation (every eval arm sets
`no_cache`; cache key already mixes `memory_epoch`), quota mutex
(check+increment atomic), temp-db cleanup on seed error, `serde(default)`
on `sources`/`escalated` so pre-field decisions still load, deterministic
audit sampling (`recent` ordering), `init` never overwrites.
